Answer-key check for the U.S. States Map Quiz

This page tests the quiz's answer key against an independent source. For each state it takes the Census Bureau's official internal point (the 2024 Census Gazetteer INTPTLAT/INTPTLONG, a coordinate guaranteed to lie inside the state), projects it with the same Albers USA projection the map uses, and checks that it falls inside the map shape the quiz labels with that state's name, and inside no other shape. It also checks that each shape's FIPS code matches the Census code for that name.
